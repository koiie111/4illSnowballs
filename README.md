# 4illSnowballs

Экспериментальный плагин CounterStrikeSharp для снежков в CS2. Сборка рассчитана на сервер с .NET 10 и CounterStrikeSharp 1.0.380 или новее. На игровом сервере движок отклонил создание старого `weapon_snowball`, поэтому этот вариант запускает отдельный снаряд с физикой CS2 и использует партиклы снежков, которые уже входят в игру.

## Управление

При спавне на игровой стороне выдаётся предмет в слоте медикамента. Для выбора используется `slot12`. Зажмите и отпустите основную атаку для обычного броска или вторичную для короткого. Если у игрока уже есть аптечка, при выдаче она имеет приоритет. Игровой интерфейс продолжает называть слот аптечкой.

Отдельный снаряд помечается на сервере. Плагин перехватывает урон от этого снаряда и воспроизводит снежный эффект. Обычные гранаты не используются для выбора или хранения снежков. Траектории проверяются только пока есть снежки в полёте. Команда `css_snowballs_status` в серверной консоли показывает количество предметов, снарядов и частиц.

## Установка для проверки

Распакуйте ZIP в папку `game/csgo`, затем загрузите карту для предзагрузки частиц. Для удаления выгрузите `4illSnowballs` командой `css_plugins unload 4illSnowballs` и удалите каталог плагина. SHA-256 ZIP указан в соседнем файле `.sha256`. Внутри архива `build.json` содержит коммит, версию API и SHA-256 DLL.

До боевой установки требуется подтвердить бросок в клиенте, внешний вид в руках и снежный эффект на экране второго игрока, а также измерить время серверного тика. Сборка CI сама по себе этих проверок не заменяет.

## Сборка

```sh
dotnet build src -c Release
dotnet run -c Release --project tests
```

GitHub Actions проверяет каждый push в `main` и каждый pull request. Почасовая задача собирает ту же ревизию с новой стабильной версией API из NuGet. Пакеты доступны в артефактах Actions и на странице Releases для тегов `v*`.
